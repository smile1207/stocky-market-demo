## 🐛 Bug 修正

1. **折線圖節點數量不足**：折線圖目前只有兩個節點，應修正為顯示完整的歷史資料點。
2. **盤中不得下單**：目前盤中狀態也能下單，應修正為僅允許在撮合瞬間生效，盤中期間禁止送出新訂單。
3. **暫停時停止 ActivityIndicator**：暫停模擬時，盤中交易旁邊的旋轉 ActivityIndicator 應同步停止，不再轉動。

## ⚙️ 撮合機制調整

4. **以 1 分鐘為單位更新時間顯示**：時間進度改為每分鐘推進一格。
5. **每 X 分鐘撮合一次，並顯示倒數計時**：撮合間隔為可設定的 X 分鐘；畫面上顯示距離下次撮合的倒數計時，倒數期間下單不生效，僅在撮合瞬間成交。
6. **新增「跳過撮合」功能**：執行一次，跳過當前這次撮合，直接進入下一個撮合週期。
7. **新增「跳過今日」功能**：直接跳到當日盤後，略過今日所有剩餘撮合。

## 🛠️ 開發者設定

8. **新增「開發者設定」頁面/區塊**，包含以下選項：
   - **設定撮合間隔**：可輸入 X 分鐘，決定每隔幾分鐘撮合一次。
   - **Debug 顯示 toggle**：可開關每支股票的需求、供給、穩定度、波動率等 debug 欄位（詳見 UI 調整第 13 點）。

## 🎨 UI / Layout 大改

9. **移除多餘的 heading**：拿掉「日次、現金、股權、通膨、熱度、穩定基金」的那個區塊標題（heading）。
10. **交易進度顯示移至「市場」分頁**：「盤中交易 OO:XX…」的倒數／進度提示不再全局顯示，改為只出現在「市場」分頁內。
11. **現金與股權顯示移至「資產」頁面**：現金餘額與股權資訊從其他位置移除，集中顯示於「資產」分頁。
12. **「定價買賣」區塊改版**：
    - 移除目前「一股『買』『賣』」的按鈕配置，改為更緊湊的佈局。
    - 按鈕改為「+1 股」（綠色）、「−1 股」（紅色），並支援多股數操作。
    - 新增「All in」（全力買入）與「全賣」（全數賣出）按鈕。
    - 顯示操作統計：「+/− X 股」以及「預計花費 / 預計兌現金額」。
13. **股票概覽預設顯示欄位調整**：
    - 預設隱藏：需求、供給、穩定度、波動率。
    - 預設顯示：成交量、漲跌。
    - 上述隱藏欄位改由「開發者設定」中的 toggle 控制，作為 debug 用途。
14. **市場頁面區塊呈現**：買入與賣出區塊放在下方且固定；股票概覽放在上方且固定；可以滑動的只有選擇標的
